# TDD Rule

> **경고: 이 규칙은 Rigid다. 상황에 맞게 변형하지 마라. 그대로 따른다.**

## 우선순위

- 프로젝트의 `CLAUDE.md` / `AGENTS.md`에 TDD 규칙이 있으면 **그쪽이 우선**한다.
- 이 파일은 **기본값(fallback)** 이다. 프로젝트 규칙이 없거나 침묵하는 부분에만 적용한다.

## 1. 적용 기준

**TDD를 반드시 적용한다:**

- 비즈니스 로직
- API (핸들러, 라우트, 외부 호출 래퍼)
- 유틸리티 / 순수 함수
- 버그 수정 (**먼저 버그를 재현하는 실패 테스트를 작성**)
- 기존 동작을 바꾸는 리팩터링의 동작 보호 테스트

**TDD가 불필요하다:**

- 타입 정의 (`interface`, `type`)
- 설정 파일 (`vite.config.ts`, `tsconfig`, `eslint.config.js` 등)
- 순수 UI (스타일, 레이아웃, 마크업만 있는 컴포넌트)
- SQL / 마이그레이션 스크립트
- 문서, 주석, 정적 자산

경계가 모호하면 **적용하는 쪽**을 택한다.

## 2. RED-GREEN-REFACTOR 사이클

### RED: 실패하는 테스트 작성

- **하나의 동작 = 하나의 테스트.** 테스트 하나에 여러 동작을 섞지 않는다.
- 테스트 이름은 기대 동작을 서술한다.
- **반드시 실행해서 실패를 확인한다.** 실행하지 않은 테스트는 테스트가 아니다.
- 실패 이유가 **"기능 미구현"** 이어야 한다. 문법 오류, import 오류, 오타, 잘못된 셋업으로 인한 실패는 RED가 아니다. 테스트를 고쳐 올바른 이유로 실패시킨다.
- 처음부터 통과하는 테스트는 아무것도 증명하지 못한다. 테스트를 의심하고 고친다.

### GREEN: 최소한의 코드

- 방금 실패한 테스트를 통과시키는 **최소한의 코드만** 작성한다.
- **YAGNI.** 테스트가 요구하지 않는 분기, 옵션, 추상화, 미래 대비 코드를 넣지 않는다.
- **신규 테스트와 기존 테스트 모두** 실행해 전부 통과함을 확인한다.
- 다른 테스트가 깨지면 GREEN이 아니다. 즉시 고친다.

### REFACTOR: 정리

- 중복 제거, 이름 개선, 헬퍼 추출만 한다.
- **모든 테스트가 green인 상태를 유지한다.** 변경 후마다 실행한다.
- **새 동작을 추가하지 않는다.** 새 동작은 다음 RED에서 시작한다.

### 반복

- 다음 동작에 대한 **RED로 돌아간다.** 요구사항이 끝날 때까지 한 사이클씩 진행한다.

## 3. 삭제 강제 규칙

- 테스트보다 **프로덕션 코드를 먼저 작성했다면, 그 코드를 삭제하고 RED부터 재시작한다.**
- **"참고용"으로 남기는 것도 금지.** 주석 처리, 별도 파일 보관, 복사해 두기 모두 안 된다. 보고 있으면 그대로 베끼게 되고, 그것은 테스트 주도가 아니다.
- 삭제는 협상 대상이 아니다.

## 4. 변명 차단표

| 변명 | 반론 |
|------|------|
| "너무 단순해서 테스트가 불필요하다" | 단순한 코드는 테스트도 30초면 쓴다. 단순하다고 믿은 코드가 가장 흔히 깨지고, 테스트는 그 단순함이 유지되는지 보장한다. |
| "나중에 테스트를 추가하겠다" | 나중은 오지 않는다. 사후 테스트는 구현에 맞춰 쓰이므로 현재 동작을 추인할 뿐 버그를 잡지 못한다. |
| "시간이 없다" | 디버깅과 회귀 수정이 테스트 작성보다 오래 걸린다. 시간이 없을수록 TDD로 재작업을 줄인다. |
| "이미 쓴 코드를 삭제하면 낭비다" | 매몰비용 오류다. 검증되지 않은 코드를 유지하는 비용이 더 크다. 테스트로 다시 쓰는 것은 빠르다. |
| "프로토타입이다" | 프로토타입은 프로덕션이 된다. 버릴 코드라고 확신하면 적용 대상 목록에서 버려지는 것이 명시된 경우만 예외다. 그 외에는 적용한다. |

## 체크리스트

- [ ] 실패하는 테스트를 먼저 썼고, 실행해서 "기능 미구현"으로 실패함을 봤다
- [ ] 최소한의 코드로 통과시켰고, 전체 테스트가 green이다
- [ ] 리팩터링 후에도 green이며 새 동작을 넣지 않았다
- [ ] 테스트 전에 작성한 프로덕션 코드는 삭제했다
